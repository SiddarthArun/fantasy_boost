# Fantasy Expert

Weekly NFL fantasy projections for Wide Receivers and Running Backs, generated by per-position XGBoost models and surfaced in a static two-column dashboard.

## Quick start

```bash
pip install nflreadpy pandas xgboost
python weekly_update.py          # writes projections.json
python -m http.server 8000       # serve from the project root
```

Then open <http://127.0.0.1:8000/frontend/>.

## How it works

`weekly_update.py` pulls three seasons of NFL play-by-play data via `nflreadpy`, engineers per-position features (EWMA of targets/touches/EPA, weighted opportunity, prior-season form, rolling defensive allowance), and trains four `XGBRegressor` models — one for WR, RB, QB, and TE to predict PPR fantasy points for the upcoming week. The top 20 projections for WRs and RBs and the top 12 for QBs and TEs are written to `projections.json`, which the dashboard reads and renders.

## Project structure

```
weekly_update.py    # data pipeline + modeling
projections.json    # generated output
main.ipynb          # exploratory analysis
frontend/
  index.html        # dashboard
  script.js         # renderer
```

## Limitations

- This setup doesn't cover defense/kicker and doesn't automatically compute flex rankings. Accuracy with QBs is a little worse than other positions as performance at QB is harder to predict and is more volatile.
- System does not account for injuries in realtime, but will prioritize players that play more games over the course of the season
- During the preseason, this system doesn't have access to data on rookies or offseason moves, but over the course of the season the rankings will include them as they accumulate fantasy relevant stats for their new teams
